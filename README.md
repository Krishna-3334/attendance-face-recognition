# Attendance Face Recognition

This is a Vite + React demo for face-recognition-based attendance using face-api models stored under `public/models`.

Quick start

1. Install dependencies

   ```bash
   npm install
   ```

2. Run dev server

   ```bash
   npm run dev
   ```

Build

```bash
npm run build
```

Notes

- If you run into dependency conflicts, try `npm install --legacy-peer-deps` or delete `node_modules` and `package-lock.json` and reinstall.
- If you're deploying to GitHub Pages or other static host, build to `dist/` and serve that.
